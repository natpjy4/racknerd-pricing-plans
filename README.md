## 同样叫虚拟主机，价格差在哪里？

差距主要来自四件事：IP 类型、资源独占程度、空间流量配额、机房位置。

共享型主机一般不提供独立 IP，通过 CNAME 访问；独立 IP 对 SEO 更有利，也不会因为同 IP 下别的网站被攻击而受牵连。资源方面，共享型是多个用户共用一台服务器的 CPU 和内存，邻居网站吃资源时你的站会跟着变慢，独享型不存在这个问题。空间和流量给得越大价格越高，机房带宽是真金白银的成本，所谓“不限流量”的方案也只是把这部分提前算进了售价。机房位置则直接影响打开速度——主机离目标访客越近越好，这也是台湾本地主机商反复强调本地机房对体验和 SEO 帮助的原因。

## 独享型比共享型贵一倍多，差价买到了什么？

差价换来的主要是独立 IP、独占资源和宽得多的带宽。企业站值得，纯个人小站未必需要。

拿阿里云的报价算一笔：共享型 119 元/年给 2GB 空间和每月 40GB 流量，仅北京单机房；独享基础版 206 元/年，变成 1核1G、5GB 空间、5Mbps 峰值带宽、每月 200GB 流量，外加独立 IP 和覆盖电信、联通、移动的 8 线 BGP 网络，机房可以从北京、杭州、香港、美国、新加坡里挑。独享豪华版 966 元/年给到 2核4G、100GB 空间，官方定位已经能跑电商、视频、团购类网站。

判断标准不复杂：网站承担获客或成交任务，独立 IP 和稳定性就是必要投入；个人博客月流量连 40GB 都用不完，共享型省下的钱拿去买域名和主题更实际。

## 常见问题

### 虚拟主机和 VPS 有什么区别？

虚拟主机是把一台物理服务器分成若干份售卖，用户共享 CPU、内存，多数情况下共享 IP，基本只能用来托管网站。VPS 则把资源完全分隔，每台有独立 IP 和完整控制权，能当独立服务器用，除了建站还能跑网盘、程序后台等别的应用。性能上 VPS 强得多，价格通常也贵一些——不过 RackNerd 这类商家已经把年付价做到了比虚拟主机还低的水平。

### 国内虚拟主机一定要备案吗？

买中国大陆机房的主机需要做 ICP 备案；香港、美国等海外主机不用备案，付款后就能直接托管网站。备案本身免费，但流程需要时间，赶上线的项目可以先放海外节点。

### 虚拟主机买好后多久能上线？

一般 3 小时到 3 天。付款后几分钟到几小时内会收到开通通知和管理登录信息；需要绑定域名、配置 SSL 证书的话，还要等 DNS 更新生效，通常 1–24 小时；涉及数据搬迁或安全配置的会更久。
